# PdfBook

Китобҳои дарсӣ барои барномаи **Биология 5–11**.

Барнома файлҳоро аз ин ҷо боргирӣ мекунад ва дар ҳофизаи телефон нигоҳ медорад,
то баъд бе интернет кор кунанд.

## Сохтор

| Папка | Давлат |
|-------|--------|
| `tj/` | 🇹🇯 Тоҷикистон |
| `uz/` | 🇺🇿 Ӯзбекистон |

## Муҳим

Номи файлҳоро **тағйир надиҳед**. Дар барнома силкаҳо ба ҳамин номҳо бастаанд —
агар номро иваз кунед, боргирӣ кор намекунад.

Агар китоби навро илова кунед, ҳаҷми дақиқи онро (байт) ба `BookCatalog.kt` нависед:

```
stat -f%z tj/tj_botanika5.pdf
```
